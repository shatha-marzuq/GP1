# واجهة ميثاق المبدئية: طريقة التشغيل

الواجهة مبنية على قصص المستخدم الجاهزة الحين (موظف الامتثال):

| قصة المستخدم | وين تلقينها في الواجهة |
|---|---|
| إنشاء حساب | تبويب **إنشاء حساب**: الاسم ورقم الجوال وكلمة المرور (8 خانات، حروف وأرقام) |
| تسجيل الدخول | تبويب **تسجيل الدخول** برقم الجوال وكلمة المرور. 5 محاولات خاطئة تقفل الرقم 5 دقائق |
| تسجيل الخروج | زر **تسجيل الخروج** أعلى الصفحة، ينهي الجلسة في السيرفر نفسه |
| رفع الشروط والأحكام (PDF / Word) | صفحة **رفع ومراجعة مستند**، مع شريط تقدم بسيط |
| استخراج النص العربي (OCR) | في النتائج تبويب **النص المستخرج من المستند**، مرتب بأرقام الصفحات |
| استرجاع مواد الهيئة لكل بند | في النتائج تبويب **البنود والمواد النظامية**: لكل بند أقرب المواد مع رقم صفحتها في لائحة الهيئة، وقرار الوكيل (مؤكدة / تحتاج مراجعة) |

كل موظف يشوف مستنداته هو بس. **التحقق من رقم الجوال برسالة (2FA) مؤجل للسبرنت الجاي** مع الباك اند وقاعدة البيانات وبوابة الرسائل.

## 1) مكان المجلد
حطي مجلد `interface/` في جذر الريبو جنب `backend/` و `docproc/` و `pipeline/`:

```
GP1/
├── backend/        (orchestrator + segmentation)
├── docproc/
├── pipeline/
├── output/chroma_db
└── interface/      ← الجديد
    ├── app.py
    ├── auth.py      (الحسابات: تسجيل، دخول، خروج)
    ├── requirements.txt
    └── static/ (index.html + logo.png)
```

## 2) المكتبات (مرة وحدة)
من جذر الريبو، وفي نفس البيئة اللي تشغلين فيها الأوركستريتر:

```bash
pip install -r docproc/mithaq_docproc/requirements.txt
pip install -r pipeline/requirements.txt
pip install -r backend/orchestrator/requirements.txt
pip install -r interface/requirements.txt
```

## 3) التشغيل

```bash
cd interface
python app.py
```

بعدها افتحي المتصفح على: **http://127.0.0.1:8000**

فيه ثلاث أوضاع للبحث في الأنظمة:

| الأمر | وش يسوي | متى نستخدمه |
|---|---|---|
| `python app.py` | وكيل الاسترجاع + خطوة النموذج اللغوي على **OpenAI** (المفتاح في `.env`، شوفي القسم 4) | **العرض للدكتورة** |
| `python app.py --no-llm` | وكيل الاسترجاع بالقواعد فقط، بدون نموذج لغوي | لو ما فيه مفتاح أو خلص الرصيد |
| `python app.py --retriever full` | البحث العادي: BGE-M3 + إعادة الترتيب مع فلتر الصناديق الخاصة، بدون الوكيل | للمقارنة |
| `python app.py --retriever bm25` | نفس قاعدة الأنظمة الحقيقية لكن بحث نصي فقط، ما يحتاج تنزيل نماذج | لو النت ضعيف أو النماذج ما نزلت |
| `python app.py --retriever stub` | مادة نظامية ثابتة (بديل) | تجربة الـ OCR والتقسيم فقط |

- أول تشغيل بالوضع الحقيقي ينزّل النماذج من HuggingFace (BGE-M3 والـ reranker، حوالي 4–5 جيجا)، فشغليه **قبل الأحد** مرة وحدة عشان تنحفظ عندك.
- لو رفعتي ملف قبل ما تجهز النماذج، يبدأ تلقائيًا أول ما تجهز.
- المنفذ مشغول؟ `python app.py --port 8001`

## 4) النموذج اللغوي (OpenAI)
حطي ملف `.env` في **جذر الريبو** (`GP1/.env`، وهو في `.gitignore` فما ينرفع لـ GitHub):

```
OPENAI_API_KEY=sk-...
RETRIEVAL_MODEL=gpt-4o
```

- `RETRIEVAL_MODEL` اختياري، الافتراضي `gpt-4o`. لو تبون أرخص: `gpt-4o-mini`.
- لما يشتغل يطبع في الترمنال `LLM step on: openai / gpt-4o`. لو المفتاح ناقص يطبع السبب ويكمل الوكيل بالقواعد بدون ما تخرب الواجهة.
- لو خلص الرصيد أو انقطع النت وقت المراجعة، البند يعتمد على ترتيب القواعد وتطلع ملاحظة صفراء فوق النتائج.

**vLLM (اختياري):** لو بغيتوا نموذج محلي بدل OpenAI، حطوا `LLM_BACKEND=vllm` في `.env` و`pip install vllm` (Linux أو WSL2 مع كرت NVIDIA). الوكيل يشغّل vLLM لحاله (الافتراضي `Qwen/Qwen2.5-7B-Instruct-AWQ`)، وإعداداته `VLLM_MODEL` و`VLLM_PORT` و`VLLM_GPU_SHARE` و`VLLM_MAX_LEN`، وسجله في `output/vllm.log`.

## 5) سيناريو العرض المقترح
1. **إنشاء حساب** ثم **تسجيل الخروج** ثم **تسجيل الدخول** من جديد.
2. **رفع ومراجعة مستند**: ارفعي ملف شروط وأحكام (مثلًا BLOM)، ويطلع شريط تقدم بحالة المراجعة.
3. **النص المستخرج من المستند**: النص العربي اللي طلعه الـ OCR بأرقام الصفحات.
4. **البنود والمواد النظامية**: كل بند برقم صفحته، ولما تفتحينه يطلع نصه وأقرب المواد مع **رقم الصفحة في لائحة الهيئة** (صفحة الـ PDF ناقص 1)، وتقدرين تفتحين نص كل مادة. فلتر "تحتاج مراجعة / مؤكدة" يوضح البنود اللي الوكيل متأكد منها.
5. **لوحة المتابعة**: المستندات اللي انرفعت وأكثر اللوائح ارتباطًا.

> نصيحة: ارفعي الملف مرة قبل العرض. النتائج تنحفظ في `interface/data/` وتبقى في لوحة المتابعة حتى لو قفلتي السيرفر، فلو صار شي وقت العرض تفتحين النتائج الجاهزة مباشرة.

## 6) ملاحظات
- الملفات المرفوعة تنحفظ في `interface/uploads/` والنتائج في `interface/data/` والحسابات في `interface/accounts/users.json` (كلها في `.gitignore`). كلمات المرور تنحفظ كـ hash (PBKDF2)، مو كنص واضح. والجلسات تنتهي لو أعدتي تشغيل السيرفر.
- الواجهة ما تعدّل أي كود في الأوركستريتر: تستدعي `build_graph` نفسه وتتابع حالته.
- ملفات Word: أرقام صفحاتها تقريبية (docproc يطلع تنبيه بهذا وتعرضه الواجهة).
